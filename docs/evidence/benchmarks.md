# Herba Codex — Evidence & Benchmarks

Every figure on this page is generated by a script in the repo from real
artifacts (run traces, processed dataset, the raw public-domain source file).
Re-generate with:

```bash
uv run python eval/evaluate.py          # accuracy metrics + bootstrap CIs
uv run python eval/ablation.py          # single-shot vs five-agent pipeline
uv run python pipelines/verify_provenance.py   # independent provenance audit
uv run python pipelines/benchmarks.py   # throughput / token / tool benchmarks
uv run pytest tests/ -q                 # 10 deterministic core tests
```

## 1 · Independent provenance audit (the headline proof)

`pipelines/verify_provenance.py` shares **no code** with the pipeline: it reads
only the final dataset and the raw Gutenberg file, and re-checks every claim
quote at its stored character span in the primary source.

| Check | Result |
|---|---|
| Claim quotes re-verified against primary source | **1,977 / 2,125 = 93.0%** |
| — plant-name quotes | 90.1% |
| — ailment quotes | 93.6% |
| — preparation quotes | 93.5% |
| Selected taxon equals a proposed & stored candidate | **100%** (324/324) |
| Evidence identifiers well-formed & canonical (PMID URL / ema.europa.eu) | **100%** (494 checked) |

The ~7% of quotes that fail primary-source verification are **itemized** in
`docs/evidence/provenance_audit.json` (they are paraphrases, heading-prefix
quotes and span-edge cases — we publish them rather than hide them, because
the Auditor-flagged failures are part of the dataset).

## 3 · Ablation — what the architecture buys

Same model (qwen3.5-9B local), same 22 scored gold entries:

| | Single unaided LLM call | Five-agent pipeline |
|---|---|---|
| Resolution accuracy@1 | 81.8% | **87.0%** |
| Quote checking | 86.4% — but of the **1 quote it chose** to produce | **82.7% — across all 266 quotes it extracts**, mechanically verified, failures kept visible |

*(0.81 vs 0.87: two matchers on the same pairs — `eval/results.json` credits only the
selected name; `eval/ablation.json` additionally credits when the gold taxon appears
among tool-verified candidates. Both are published.)*

The pipeline's advantage is not a magic accuracy jump; it is that every one of
the 266 extracted quotes is *individually verified and auditable*, every
taxon is tool-checked, and every grade carries provenance — capabilities the
single-shot baseline does not attempt.

## 5 · Engineering determinism

- Segmentation is byte-deterministic (tested): identical runs produce identical
  entries with stable character offsets.
- KG construction, quote verification, metrics and exports are pure Python —
  no LLM involved.
- 10 deterministic core tests pass (`uv run pytest tests/ -q`).
- Per-entry JSON checkpoints: any run crash resumes exactly where it stopped.
