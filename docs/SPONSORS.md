## How Herba Codex relates to the sponsor tools (honest disclosure)

- **No sponsor-provided API or technology was required by the tracks**, and we
  have integrated none — every external dependency is an open, attributed data
  source (Kew POWO, GBIF, EMA, PubMed, PubChem, Gutenberg). We say this
  plainly rather than decorating the project with sponsor logos.
- **Aitho** is directly useful to our remaining deliverable: we recommend the
  team rehearse the pitch video with it (speak-the-script timing practice) —
  a genuine, honest use of an in-kind sponsor tool.
- We thank all four organisations plus the ETHCSTWIN team for running the
  first edition of this hackathon.
